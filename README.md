# KHUNG — Tách ảnh từ video

Ứng dụng chạy hoàn toàn trên trình duyệt (TanStack Start + Nitro, preset Vercel).
Không cần biến môi trường, không cần database.

## Chạy local
    npm install
    npm run dev

## Deploy lên Vercel
1. Đẩy thư mục này lên GitHub.
2. Vercel → Add New → Project → chọn repo.
3. Build Command: `npm run build` (không cần Output Directory) → Deploy.

Hoặc dùng CLI: `npx vercel` rồi `npx vercel --prod`.
